# Tallybook UI component catalog

This is a concise inventory of shared UI building blocks. Use it to choose an existing component before
creating another one. Visual tokens, interaction rules, and ownership remain defined in
[architecture.md](architecture.md).

## Foundations

| Component | Use it for | Do not use it for |
|---|---|---|
| `TallybookTheme` | Providing the shared color, typography, spacing, dimension, radius, and motion tokens | Storing feature state or screen layout decisions |
| `TallybookScreenFrame` | A top-level screen with safe-area policy, screen insets, and optional bottom chrome | A modal or a nested card |
| `TallybookScreenHeader` | A page title row with optional navigation and actions (Categories, Tags) | A sheet title (use `TallybookSheetTitle`); its 48dp controls center on the title and extend past the row, so the title sits where title-only headers put it |
| `TallybookSurface` | A tokenized card or the visual foundation of another shared component | A feature-specific layout with business behavior |
| `TallybookSheetForm` | A modal sheet form with text inputs: edit/add movimiento, the Categories editor, picker quick-create and the tag sheet | Header and footer stay outside a body that scrolls up to a maximum height (optionally a minimum one). The sheet never moves for the keyboard: while it is open the body keeps its resting height, gains the keyboard height as scroll room, keeps an input marked `revealWhenFocused()` centered above it on Android, and the footer gives way until the keyboard closes. |
| `TallybookModalBottomSheet` | Modal creation, movimiento detail/edit or category selection | A permanent screen or navigation destination. Optional `onBack` runs in the native modal dispatcher; content modes with different natural heights need distinct detent identifiers, and each tracks its own natural height as the content grows. |
| `TallybookModalDialog` | A form-like modal over the app, such as the sentence entry | Card centered vertically when it opens, with a narrow `space12` side gutter and `space24` inner padding. That top edge is kept while the content grows, so height changes animate downward without a jump; only the keyboard or the screen edge moves it up, by the minimum needed, and it returns to the captured top when they leave. The height left above the keyboard bounds its content, which must tolerate that. Scrim tap and Back call `onDismissRequest`; `onHidden` runs after the exit animation, once the content has left composition. |
| `TallybookConfirmationDialog` | Confirming a decision over an existing screen or sheet | Presenting a form or replacing a bottom sheet |

## Actions and selection

| Component | Use it for | Notes |
|---|---|---|
| `TallybookButton` | A primary, filled action, optionally with an icon | Use the action label as the visible content; it preserves the shared subtle press feedback. `TallybookButtonDefaults.destructiveColors()` supplies paired danger colors for a destructive CTA; confirmation callers select them with `confirmColors`. |
| `TallybookTextButton` | A secondary, low-emphasis action with text and optional icon | Use when a filled background would overstate hierarchy. |
| `TallybookIconButton` | A compact icon-only action such as search clear or a contextual control | It requires an accessibility description, supports neutral, brand and ghost (icon only, no container, for navigation over the screen background) styles, accepts explicit colors, and takes an optional icon size (default `iconButtonIconSize`). `destructiveColors()` pairs a soft red container with the danger icon color. |
| `TallybookSegmentedControl` | Selecting exactly one peer option, such as Gasto or Ingreso | Tonal and neutral styles share selection behavior. `labelStyle` lets a caller choose a typography token without changing other controls. |
| `TallybookSwitchRow` | A labeled on/off choice, such as Repetir | The whole row is the `Role.Switch` toggle with a 48 dp minimum height; the track and thumb use theme tokens and fade with the shared duration. Optional supporting text sits under the label. |
| `FrecuenciaField`, `RepetirField` | Choosing a recurrencia's frecuencia (`core/ui/recurrencia`) | `FrecuenciaField` is a labeled neutral segmented control, Mensual first. `RepetirField` pairs `TallybookSwitchRow` with it, shown only while on; a null frecuencia means off. Creation's form and summary use `RepetirField`; the recurrencia sheet uses `FrecuenciaField`. |
| `TallybookPeriodPickerHeader` | Giving the active day, week, or month its contextual title next to the year control | The caller supplies the title, optional subtitle, and year-control slot. |
| `TallybookPeriodPickerRow` | Choosing one bounded day, week, or month period in a horizontally scrollable row | The caller owns the typed period values; optional captions and data indicators are presentational metadata. |
| `TallybookYearMenu` | Changing the year that scopes a period picker | It is an anchored, accessible popup with the same scrim and motion as the date picker; four year rows are visible before its list scrolls. |
| `TallybookSelectionField` | Opening a dedicated selection flow from a form | It displays a value or placeholder; it is not a free-text input or inline dropdown. |
| `CategoryChip` | Selecting a category inside the category picker, or opening one from the Categories screen | Use it in the selection flow, not as a substitute for the form field. `trailingCheck` adds a trailing check mark; `trailingContent` follows the name (the Categories screen's movimiento count and hidden mark, read through the chip's state description); a disabled chip is dimmed. `pending` swaps in the neutral dashed treatment for Otros. A `null` `onClick` renders it as non-interactive content that keeps the selected semantics. |
| `CategoryTag` | Showing the selected category at the one tag size (28 dp avatar, 36 dp tall) | Tinted fill; `pending` swaps in the neutral dashed Otros treatment; `onRemove` adds a trailing × whose 48 dp tap area is a separate button labelled with the category name. The tag body is never tappable and keeps selected semantics. |
| `CategorySuggestionTag` | Offering one category as a tappable suggestion | Outlined with a leading plus and plain button semantics. `dimmed` borrows the disabled look while staying tappable, for a suggestion that would replace the selected category. |
| `CategorySingleField` | The Category section of every movimiento surface | Stateless: the selected category (or the dashed Otros fallback with its "to complete" caption), suggestions that act as a switch (dimmed while a real category is selected, still tappable and announced as replacing it) and a "Choose" tag that opens the picker. `deselectable` adds a × that reports `onDeselect`; the editor leaves it off so a movimiento always keeps one category. |
| `CategoryPickerSheet` | Choosing the one category of a movimiento | One level, no drill-in: a search field, a pinned "Selected:" row showing the selected category as a small `CategoryTag` (none for Otros) that stays while searching, then `CategoryChip`s grouped by family (`categoryFamilies`, shared with the Search filters), the parent first and its children after, with extra space between families and no headers, opened scrolled to the selected category's family; a search lists every match in one flat block, and one without results shows `TallybookSearchEmptyState`. A tap reports the category and closes the sheet; tapping the already selected one only closes it. With `creation`, that empty state offers quick-create as its text action, opening a pane of the same sheet. Creation, review and editing share it; the caller excludes Otros and hidden categories. |
| `CategoryForm` | The fields of a custom category, shared by picker quick-create (`COMPACT`) and the Categories editor (`FULL`) | Stateless over `CategoryDraftState` and `CategoryFormActions`; callers own title, save and dismissal. Name with counter/error, current-icon avatar expanding to a 48 dp radio grid (the dashed Otros icon is excluded), tint options that preview the current icon as an avatar in each tint, and description with counter; `COMPACT` keeps tint and description behind "More options". Duplicate names show as the name error; the caller supplies the optional action ("Use X", "Open X"), never shown for Otros. |
| `EtiquetaTag` | Showing a selected tag | Neutral chip with a leading `#` and no tint of its own. `onRemove` adds a trailing × whose 48 dp tap area is a separate button labelled with the tag name; the tag body is never tappable. |
| `EtiquetaSuggestionTag` | Offering one tag as a tappable suggestion | Outlined with a leading plus and plain button semantics. |
| `EtiquetaAddTag` | The "+ Add" tag that opens the tag picker | Neutral outline shared with the category "Choose" tag; its accessibility label is "Add tag". |
| `EtiquetaChip` | Selecting a tag in the tag picker and the Search filters, or opening one from the Tags screen | `count` adds the movimiento count after the name, announced as the chip's state. A `null` `onClick` renders non-interactive content that keeps the selected semantics. |
| `EtiquetaTagField` | The optional Tags section of every movimiento surface | Stateless: `EtiquetaSectionHeading` ("Tags" plus a faint caption "optional" on the same baseline, read as one heading; also used by the unavailable-catalog retry), the selected tags in display order with ×, and "+ Add" until `max`. Suggestions already selected are skipped and none is offered once the field is full. |
| `EtiquetaPickerSheet` | Choosing a movimiento's tags | A title row with "Done (n)" at its end, so closing stays reachable with the keyboard open; a search field; the selected tags as removable tags; then a results area with the fixed `pickerResultsHeight` (the category picker's results height), so the sheet opens tall and the keyboard never covers the search. Every matching `EtiquetaChip` is a toggle reporting the whole new selection; additions stop at `max` with a hint under the selected tags. Messages sit at the top of that area, right under the search, so the keyboard never covers them: without any tag, a `#` icon, the empty message and a hint to type the first name; a search without results, `TallybookSearchEmptyState` with a text action creating the trimmed query and, while the query still names `failedCreateNombre`, its error explaining the failed create; a query longer than the tag name limit shows that limit as the error instead of the action. |
| `MedioPagoControl` | Choosing the one medio of a movimiento | Wrapping options with icon and label, filtered by the caller to the medios the tipo allows; a `null` selection shows every option unselected, as an undecided sentence leaves it. |
| `CuentaSelectorField` | Showing a movimiento's account under the caller's Account heading | With one compatible account it shows it without opening a picker; otherwise it opens `CuentaPickerSheet`. `cuentaDisplayName` adds the currency code outside the primary currency. With no compatible account the caller shows its empty state. |
| `CuentaPickerSheet` | Choosing one account among those the caller limited to live, active and medio-compatible ones | A tap reports the account and closes the sheet; a search field appears from eight accounts (`CUENTA_PICKER_SEARCH_THRESHOLD`) and shares `PickerSearchState`. |
| `MovimientoCuentaField` | The Medio and Account sections of every movimiento surface | Stateless over `MovimientoCuentaUi`: `MedioPagoControl`, then `CuentaSelectorField`, the empty state with in-place account creation, and the other accounts a sentence named as suggestion tags. A missing medio or an account error scrolls the field into view. |
| `PickerSearchState`, `rememberPickerSearchState` | The query of a searchable picker sheet (`TallybookPickerSearch.kt`) | Keeps the height the content had before searching, through `pickerSearchHeight`, so results that shrink do not move the sheet under the keyboard. Both pickers share it. |

## Sheet headings

Existing and future bottom sheets use these shared headings and the standard defined in
[UI architecture](architecture.md#bottom-sheet-typography-hierarchy).

| Component | Use it for | Notes |
|---|---|---|
| `TallybookSheetTitle` | The visible primary title of a bottom sheet | Manrope sheetTitle token, 20sp/800; heading semantics and caller placement. |
| `TallybookSectionHeading` | A section label above its values or controls | Manrope sectionHeading token, 16sp/600; tertiary gray, optional error color and heading semantics. |

## Inputs and feedback

| Component | Use it for | Notes |
|---|---|---|
| `TallybookInputLabel` | Identifying an input field, including Description | Independent inputLabel token, 14sp/400; gray or supplied error color, without section-heading semantics. |
| `TallybookTextField` | A themed single-line or multi-line text input with label, placeholder, error, and leading or trailing content | It owns focus, cursor, border, and disabled appearance; optional `labelContent` preserves the semantic label. `minLines`/`maxLines` fix the height of a multi-line field that must not grow its container. |
| `TallybookSearchField` | Search queries with a search affordance and optional clear action | Its outer size remains stable while the query changes. |
| `TallybookAmountInput` | A prominent monetary value with its currency symbol, decimal keyboard, and field feedback | It does not parse, normalize, or format while the user is editing; optional `labelContent` supplies a field label. |
| `TallybookDateChipPicker` | Selecting one calendar date from a compact date chip | S and M variants preserve the minimum touch target; both apply a date immediately and support inclusive `minDate`/`maxDate`. Omitted bounds preserve existing callers. |
| `TallybookChoicePill` | Choosing one option in a wrapping group, including Search date presets and type | Caller owns selection and layout. Centered 36 dp visual surface, minimum 48 dp target, selected/disabled semantics and no press ripple or shading. A multi-select group (Search accounts) passes `role = Role.Button`. |
| `TallybookFilterTag` | Showing an applied filter with one remove action | Compact 28 dp surface and caption text, centered in a minimum 48 dp target. Caller supplies the localized remove description, an optional category palette and an optional `leadingIcon`. |
| `TallybookSearchEmptyState` | A search without results: both pickers and the Categories and Tags screens | Stateless: a decorative Lucide `SearchX` icon (the search-empty icon), a centered message and an optional `action` slot (a `TallybookTextButton` sized to its label) with an optional `error` announced politely under it. It stays top-aligned with a `space16` top padding; under a `space16`-spaced search field the search sits 32 dp above the icon, and a `space16` spacer plus the action's touch-target inset places its label the same 32 dp below the message. Not for a catalog with no items or the Search destination's titled empty layout. |
| `TallybookFieldMessage` | Error or supporting text associated with a field | Prefer the field's `message` parameter when it is available. |
| `TallybookSnackbar`, `TallybookSnackbarHost` | The current localized notification in a caller-owned queue | Plain rendering accepts leading/action/dismiss slots and a root modifier; the host times only the visible head. Callers own FIFO delivery, token/revision acceptance, foreground/modal activity and placement/insets; `TallybookScreenSnackbar` is the action-less placement shared by the Categories and Tags screens. Duration and Close rules follow the shared [presentation policy](architecture.md#snackbar-presentation). Busy exposes leading progress and disables any Close without click semantics. |
| `ManagementFeedbackRoute` | The shell host for movimiento and transfer management feedback | Renders the head of the shell's one `ManagementFeedbackQueue` with `TallybookSnackbar`; messages, actions and statuses come from typed tables per subject and kind. A missing-account restore is a warning without Retry. |
| `TallybookSkeleton`, `TallybookSkeletonLine`, `TallybookSkeletonCard` | Static placeholders for data whose layout is known | Lines measure typography and font scaling; cards accept a content slot. The caller owns feedback timing and loading semantics; sample text is excluded from accessibility. |
| `RetainedLoadState<Content, Failure>` | Owning one complete snapshot and typed loading/error status in a ViewModel | `refreshing()` and `failed(error)` preserve the last snapshot; replace it with `Ready(value)` on success. A query change starts `Loading()` without old data. Completed empty results retain their content identity. |
| `LoadingPresentation`, `rememberLoadingPresentation`, `deferLoading` | Deferring initial visual loading feedback while preserving a coherent rendered snapshot | Select `isInitialLoading` and a typed `requestKey` only from screen state. Metadata must not change request identity; cached content, results and errors bypass the delay. Skeleton layout and semantics belong to each screen. |
| `InputFocusReveal` | Android-only smooth centering of an already focused form input inside a scrollable sheet | It is an implementation helper, not a feature-level component. iOS keeps its native input relocation. |
| `TallybookDismissGuard` | Protecting unsaved drafts when a modal closes | A non-visual state holder; callers provide `hasUnsavedChanges`, discard and dismissal callbacks. |

## Content and navigation

| Component | Use it for | Notes |
|---|---|---|
| `BalanceCard` | The Home or selected-period summary of balance and income/expense context | Full-width stacked income/expense rows with trailing amounts. Caller supplies the localized label, typed secondary-amount formatter and optional feedback footer; reuse its matching skeleton. |
| `BalanceCardSkeleton` | A pending Home balance summary | Matches the existing card's typography, spacing, surfaces and income/expense mini-cards; placeholder text has no semantics. |
| `MovimientoRow` | A compact movement item in a list | Optional `onClick` opens the stored row ID through the caller; placeholders remain non-interactive. Shared card amounts and skeletons use the size14 token. Callers pass `pending` for Otros: a dashed avatar and a muted "to complete" label announced with the row. The amount line starts with a silent medio icon; the medio label is announced last, once. Rows never show tags or the account name. |
| `PendingOccurrenceRow`, `ScheduledRecurrenciaRow` | A recurrencia in Recurrentes (`feature/recurrentes/ui`) | Both render the template through `MovimientoRowContent` with the due date ("pending since") or the frecuencia and next date as the subtitle, announced with title and amount as one node, and their own click label. A pending date after the recurrencia's oldest one is not interactive and says why. |
| `CuentaBalanceRow` | One account with its balance (Accounts) | A credit card shows its estimated debt, or a positive balance as credit, plus this cycle's spending; the currency code appears outside the primary currency. Announced as one unit with its click label. |
| `CuentaTypeIcon`, `MedioPagoIcon` | The icon of an account type or medio | Typed lookup tables with the label as default description; pass `null` when the label is already visible. The Transferencia medio avoids the two-way arrows reserved for transfers between own accounts. Labels come from `TipoCuenta.labelResource` and `MedioPago.labelResource`. |
| `TransferenciaRowContent` | A transfer between the user's own accounts in a list (Accounts' recent transfers, and History and Search through `ActividadTransferenciaRow`) | Neutral: no sign or status color, since a transfer is neither income nor expense. The caller formats the route names (currency code for non-primary accounts), picks which side's amount to show and the optional supporting line; announced as one "Transfer between your accounts, from … to …" unit. |
| `ActividadTransferenciaRow` | A transfer inside History and Search day groups | Wraps `TransferenciaRowContent` with the viewed currency's side of the amount, the description as supporting line, a localized fallback for an account no longer listed and the currency code for accounts outside the primary currency. |
| `MonedaSelector` | Choosing the currency History and Search show | One `TallybookChoicePill` per currency code after a Currency label; callers render it only while live accounts exist in more than one currency. |
| `MedioPagoFilterControl` | Search's multi-select medio dimension | Same option look as `MedioPagoControl` (icon and label) with button semantics; every medio can be toggled independently. |
| `MovimientoSentenceStep` | The content of the sentence dialog | Stateless: a `MovimientoSentenceUi` and callbacks. A fixed title sits above a scrolling body (labeled two-line input, a "Detected" card with the tipo and date badges, the amount when found, the Category section and the Tags section, Continue, the dictation microphone and "Fill manually"), because the keyboard only shrinks the dialog's available height. |
| `MovimientoTypeBadge`, `MovimientoDateBadge` | The tipo and relative fecha of a movimiento as tinted pills | `Regular` for the dialog, `Large` for the review sheet. The tipo icon, label and accent come from one typed table shared with the type selector and the balance card. |
| `VoiceDictationButton` | The "or" divider, title, hold-to-talk microphone disc and its caption under the main entry action | Stateless: a `VoiceInputUi` and callbacks. Press starts, lifting the finger (even off the disc) ends, and sliding `voiceSlideToCancel` to the left calls `onDiscard` instead, with `SlideToCancelGuide` (label and chevrons, hidden from screen readers) left of the disc while it can; the disc turns green once the microphone is open. Screen readers get a button whose activation toggles listening and, while listening, a "Cancel dictation" action. Notices and "Open settings" replace the caption. Disabled with "not available" when the device has no on-device recognizer. |
| `MovimientoSummaryStep` | The review content after the sentence | Stateless: title and subtitle, labeled sections (Type and Date as large badges side by side, Amount, quoted Title, the Category section with its suggestions and the Tags section; no text input) and the Edit movimiento (left) / Save (right) footer anchored at the bottom, at least `space32` below the content. Callers give it a minimum height to make the sheet tall (`rememberReviewMinimumHeight`). Amount review and missing-amount messages are announced. |
| `MovimientoReviewStep` | The review of a split sentence, in place of the summary | Stateless over `MovimientoReviewUi`: header with the part count and total (labelled when another currency is excluded), one `ReviewPartRow` per part (signed amount, título, category tag, ×, the amount-review hint and a diverged tipo under the título), the shared tipo and date, `MovimientoCuentaField`, Tags and Repetir, and the Unir en uno (left, disabled while `canJoin` is false) / Save N (right) footer. Same minimum height as the summary. |
| `MovimientoDetectedParts` | The Detected card of the sentence dialog while the sentence splits | "N movimientos" with the total and one compact row per part (amount, título, category, Otros shown as no category). Replaces the single amount and the Category and Tags sections. |
| `ReviewPartCategorySheet` | Changing one part's category from its tag in the review | Small sheet with that part's suggestions, clear and "Choose", which opens the single-select picker for that part. |
| `MovimientoRowSkeleton` | A pending movement row | Shares the current row's avatar size, spacing and surface, with title, description and amount lines stacked like the row; the amount line reserves the medio icon slot. |
| `TallybookBottomNavigation` | Stable primary destinations and the centered Add movimiento action | A `null` selection callback renders a non-interactive bar for catalogs and fixtures. |
| `TallybookNavHost` | Connecting approved routes to shared navigation UI | It owns route composition, not feature business logic. |

## Charts

`core/ui/chart` holds the Statistics drawings. Values are `Double`s derived from `Money` for drawing
only; callers format every visible amount. Each chart is a single accessibility node whose required
`contentDescription` carries the localized summary. Column and line charts use Vico (see
[stack](../stack.md)); the donut and bars are plain Compose. Colors follow the
[rank rule](architecture.md#statistics-presentation).

| Component | Use it for | Notes |
|---|---|---|
| `TallybookDonut`, `DonutSlice` | Parts of a whole, such as an exclusive distribution | Slices in basis points (10,000 fills the ring) drawn clockwise from the top over a track; a total above 100% is clipped. The `center` slot holds the total and caption. |
| `TallybookDistributionRow` | One group of a distribution: color dot, name, optional `ChangeIndicator`, amount, share and a proportional bar | The caller passes the share text and its `fraction`. With `onClick` the whole row is one button with the shared tap feedback; without it the row is merged, non-interactive content. At least the minimum touch target tall; the name wraps to two lines and the share column grows with font scale. |
| `TallybookTrendChart`, `TrendPoint` | Monthly gastos and ingresos as grouped columns with the balance as a line | Unselected months dim and a partial month keeps a full-color outline over a faint fill. Every month is an equal-width tap target and a custom accessibility action; the selected month is the node's state. |
| `TallybookPaceChart` | The month's cumulative gasto against a straight line to the average month, with a dotted projection to the month's end | One value per elapsed day, the last being today, which carries a persistent labelled marker. |
| `TallybookCategoryTrendChart` | One category's monthly totals as columns in its color, with the average as a dashed line | `partialLast` gives the last column the partial treatment. |
| `TallybookChartTheme`, `ProvideTallybookChartTheme` | Series colors (gastos danger, ingresos brand, balance primary foreground, average faint), chart alphas and the animation spec | Every Vico chart is wrapped in the provider, so Vico defaults come from Tallybook tokens instead of Material. |
| `chartPaletteIndex`, `chartRankColor`, `chartRestColor` | The color of the n-th ranked group, shared by Statistics and Home | `chartPaletteIndex` is the pure rule (null past the palette); the composables resolve it, falling back to `chartRestColor` (`foreground.faint`). |
| `shareText`, `shareFraction` | A share in basis points as rounded percent text, or as a bar fraction | Percent text rounds half up; the small-share wording follows [business logic](../business-logic.md#statistics). |
| `ChartSlotLabels`, `EmphasisColumnProvider` | Month labels under column charts, and column styling for selection and partial months | Internal parts of the column charts: the labels share Vico's equal x slots, so a label sits under its column. |

## Reference environment

`UiCatalogScreen` is the in-app debug catalog used to inspect component states, themes, and interaction
variants on physical devices. It is a verification surface; production screens should consume the shared
components directly.

The current creation flow and retained category capabilities are documented in
[Add movimiento](../features/add-movimiento.md).
